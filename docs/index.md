# Refined Canvas Privacy Policy

Refined Canvas is an independent browser extension for Canvas LMS. It reads and modifies elements on Canvas LMS pages and their embedded Canvas DocViewer previews to apply appearance, navigation, and reading improvements. The optional final exam calculator reads the displayed course grade and assignment weights and uses them with the values you enter to calculate an estimate in your browser.

The extension stores your preferences and document bookmarks, including any labels you enter, in Chrome's local extension storage. Bookmarks are associated with the Canvas site address and page path so they can be restored when you return. The calculator keeps its inputs in the current page. Refined Canvas has no analytics or developer server and does not transmit your grades, calculator inputs, bookmarks, or settings to the developer or third parties. Canvas and Chrome provide their own services under their respective privacy policies.

You can delete bookmarks using the document toolbar. Removing the extension clears its local extension storage. For questions about this policy, use the Support contact on the Refined Canvas Chrome Web Store listing.
