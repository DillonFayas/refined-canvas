# Refined Canvas store submission

## Store listing copy

Refined Canvas improves the MSOE Canvas experience with dark mode, course navigation shortcuts, document reading controls and bookmarks, and a final exam score calculator. The extension is designed for msoe.instructure.com and is independently developed. It is not affiliated with MSOE or Instructure.

## Privacy practices

- Single purpose: Improve the appearance, navigation, and reading experience of MSOE Canvas, including an on-page tool for interpreting course grades.
- Storage permission: Save appearance settings and document bookmarks in Chrome's local extension storage.
- MSOE Canvas site access: Apply the interface changes and read displayed grades and weights when using the calculator.
- Canvas DocViewer site access: Style embedded previews and coordinate document navigation with the MSOE Canvas parent page.
- Remote code: All extension scripts and styles are bundled. There is no analytics or developer backend.
- Data handling: Displayed grades and calculator inputs are processed in the browser. Preferences and bookmarks are stored locally. Publish the accompanying privacy policy and enter its public URL.

## Reviewer test instructions

Sign in to an authorized MSOE Canvas test account. Open a course and toggle dark mode and formatting from the extension popup. Open Grades in a weighted course, expand the final exam calculator, and enter a target grade. Open an embedded PDF from a module and verify the document toolbar, bookmarks, and previous/next module links. Provide approved test access in the dashboard if Google needs it. Use a dedicated test account instead of your personal credentials.
